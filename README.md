# 🏨 Online Hotel Booking

A modern, responsive frontend web application for an online hotel booking system. This project allows users to browse available rooms, view hotel details, and go through a booking interface. 

## ✨ Features

*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices using CSS Flexbox/Grid.
*   **Interactive UI:** Dynamic elements and smooth user experience powered by vanilla JavaScript.
*   **Room Listings:** Browse different rooms with details like pricing, amenities, and images.
*   **Booking Interface:** A user-friendly form to simulate booking a hotel room.
*   **Clean Layout:** Modern and accessible design using custom CSS.

## 🛠️ Tech Stack

This project is built using core frontend web technologies:

*   **HTML5:** For semantic and structured markup.
*   **CSS3:** For styling, animations, and responsive layouts.
*   **JavaScript (ES6+):** For DOM manipulation, interactivity, and application logic.
